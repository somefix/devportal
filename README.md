# Devportal

Расширение Chrome и Firefox для переключения между окружениями проектов.
Интерфейс настроек и popup реализованы на PrimeVue.

## Разработка

Требуется Node.js 22.16+ и npm.

```sh
npm ci
npm run dev
npm run compile
npm test
npm run build
npm run build:firefox
```

Для установки в Chrome откройте `chrome://extensions`, включите режим разработчика
и загрузите распакованную папку `.output/chrome-mv3` после сборки.

## Использование

1. Откройте настройки расширения, добавьте проект и заполните адреса Local, Dev, Stage и Prod.
   Окружения можно переименовывать, добавлять и удалять через меню строки.
2. Выберите окружение по умолчанию через меню строки. Укажите префикс для удаления
   (например, `/app`), сохранение query и hash и способ открытия. Нажмите «Сохранить».
3. Нажмите иконку расширения на веб-странице. Проект определяется по точному хосту
   и порту текущего URL. Выберите окружение, проверьте адрес и откройте его.
4. `Alt+Shift+L` открывает окружение по умолчанию для определённого проекта
   (или выбранного в настройках). Сочетание можно изменить в настройках команд браузера.
5. Контекстное меню ссылки содержит открытие и копирование адресов окружений
   выбранного сохранённого проекта. Копирование открывает страницу расширения,
   которая копирует адрес; если браузер блокирует доступ к буферу, нажмите кнопку копирования.

Адрес без протокола получает HTTPS; `localhost`, `127.0.0.1` и `[::1]` получают HTTP.
Явно заданный протокол сохраняется. Удаление префикса работает на границе сегмента:
`/app/tasks` → `/tasks`, а `/application` не меняется. Затем применяются правила замены.

Настройки сохраняются в синхронизируемом хранилище браузера. Старые хосты, выбранный
хост и правила подхватываются в один проект; исходные данные сохраняются.
Кнопки импорта и экспорта работают с JSON версии 1. Импорт проверяется до применения
и записывается в хранилище только после нажатия «Сохранить». История хранит последние
50 уникальных исходных ссылок. При ошибке сохранения (включая квоту sync) интерфейс
показывает сообщение.

Разрешения: storage, activeTab, contextMenus и clipboardWrite.
