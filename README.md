# Devportal

Расширение Chrome и Firefox для переключения между окружениями проектов.
Интерфейс настроек и popup реализованы на PrimeVue.

## Промоматериалы

Пять слайдов с описанием возможностей и две промокартинки находятся в
[docs/promo](docs/promo/README.md). Для просмотра откройте
[галерею](docs/promo/index.html) в браузере.

## Разработка

Требуется Node.js 22.16+ и npm.

```sh
npm ci
npm run dev
npm run format:check
npm run compile
npm test
npm run build
npm run build:firefox
```

Для установки в Chrome откройте `chrome://extensions`, включите режим разработчика
и загрузите распакованную папку `.output/chrome-mv3` после сборки.

Для форматирования исходников используйте `npm run format`.

## Использование

1. При первом запуске доступен один проект с окружением Local по адресу `localhost:3000`.
   Проекты, добавленные в настройках, тоже получают одно окружение Local с этим адресом.
2. Выберите окружение по умолчанию через меню строки. Добавьте правила замены пути,
   настройте сохранение query и hash и способ открытия. Настройки сохраняются автоматически.
3. Нажмите иконку расширения на веб-странице. Проект определяется по точному хосту
   и порту текущего URL. Выберите окружение, проверьте адрес и откройте его.
4. `Alt+Shift+L` открывает окружение по умолчанию для определённого проекта
   (или выбранного в настройках). `Alt+Shift+P` переключает действие кнопки расширения
   между попапом и прямым открытием окружения по умолчанию. Сочетания можно изменить
   в настройках команд браузера.
5. Контекстное меню ссылки содержит открытие и копирование адресов окружений
   выбранного сохранённого проекта. Копирование открывает страницу расширения,
   которая копирует адрес; если браузер блокирует доступ к буферу, нажмите кнопку копирования.

Адрес без протокола получает HTTPS; `localhost`, `127.0.0.1` и `[::1]` получают HTTP.
Явно заданный протокол сохраняется. Правила замены применяются к пути по порядку.
Например, правило `app/market/` → `/` меняет путь `/app/market/tasks` на `/tasks`.
Ранее сохранённый префикс переносится в начало списка правил и применяется только к началу пути.

Настройки сохраняются в синхронизируемом хранилище браузера. Старые хосты, выбранный
хост и правила подхватываются в один проект; исходные данные сохраняются.
При переносе старых настроек клик по иконке продолжает открывать окружение по умолчанию.
Для новых установок включён попап; явно выбранное действие иконки сохраняется при обновлениях.
После обновления версии на иконке появляется бейдж `NEW` с приглашением открыть параметры
в подсказке. Бейдж исчезает после открытия параметров.
У нового окружения нужно заполнить название и адрес, а у нового правила — оба поля.
Кнопки импорта и экспорта работают с JSON версии 1. Импорт проверяется до применения
и сохраняется автоматически. Внизу настроек отображаются последние 50 уникальных исходных URL
успешных переходов через расширение. Открытие из истории исходного URL или его версии
для окружения выбранного проекта поднимает исходную ссылку наверх. Копирование URL
и обычная навигация браузера не создают записи. При ошибке сохранения интерфейс показывает сообщение.

Разрешения: storage, activeTab, contextMenus и clipboardWrite.
