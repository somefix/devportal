# Промоматериалы Devportal

Пять слайдов на русском языке для описания расширения и две промокартинки.
Слайды поставляются отдельными PNG, а не редактируемой презентацией.
Размер каждого слайда — 1586 × 992 px, компактной промокартинки — 1573 × 1000 px,
широкого баннера — 1983 × 793 px. Это исходные изображения генерации.

| Файл                     | Содержание                                             |
| ------------------------ | ------------------------------------------------------ |
| `slide-01-overview.png`  | Переход с прода на локалку с сохранением пути страницы |
| `slide-02-projects.png`  | Проекты и выбор Local, Dev, Stage, Prod                |
| `slide-03-url-rules.png` | Правила замены пути и настройки query/hash             |
| `slide-04-shortcuts.png` | Alt+Shift+L и контекстное меню ссылки                  |
| `slide-05-history.png`   | История переходов, импорт и экспорт настроек           |
| `promo-small.png`        | Компактная промокартинка                               |
| `promo-marquee.png`      | Широкий промобаннер                                    |

Изображения созданы встроенным инструментом ImageGen. Полные промпты сохранены
в [prompts.json](prompts.json). Иллюстрации интерфейса демонстрационные, это не
скриншоты работающего расширения. Возможности сверены с README и исходным кодом.
Адреса `example.com` используются для примеров.

Материалы хранятся вне `public`, поэтому не увеличивают размер сборки расширения.
Перед публикацией в конкретном магазине проверьте его требования к размерам изображений.
